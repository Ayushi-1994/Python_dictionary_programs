PROGRAM: Word Frequency

PROBLEM:
Count occurrences of each word in a sentence.

INPUT:
python is easy python is powerful

OUTPUT:
{'python': 2, 'is': 2, 'easy': 1, 'powerful': 1}

LOGIC:
1. Split sentence into words.
2. Traverse each word.
3. Store count in dictionary.
4. Print final frequency dictionary.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(n)
