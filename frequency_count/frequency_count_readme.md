PROGRAM: Frequency Count

PROBLEM:
Count frequency of each character in a string.

INPUT:
banana

OUTPUT:
{'b': 1, 'a': 3, 'n': 2}

LOGIC:
1. Create an empty dictionary.
2. Traverse each character.
3. Increment count if character exists.
4. Otherwise initialize with 1.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(n)
