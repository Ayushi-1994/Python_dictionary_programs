PROGRAM: Sort Dictionary by Value

PROBLEM:
Sort dictionary according to values.

INPUT:
{'a':5,'b':1,'c':3}

OUTPUT:
{'b':1,'c':3,'a':5}

LOGIC:
1. Convert dictionary into items.
2. Sort using value as key.
3. Convert sorted result back to dictionary.

TIME COMPLEXITY:
O(n log n)

SPACE COMPLEXITY:
O(n)
