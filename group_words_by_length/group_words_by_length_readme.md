PROGRAM: Group Words by Length

PROBLEM:
Group words according to their length.

INPUT:
['cat','dog','apple','ball']

OUTPUT:
{3:['cat','dog'],4:['ball'],5:['apple']}

LOGIC:
1. Find length of each word.
2. Use length as dictionary key.
3. Store words having same length together.

TIME COMPLEXITY:
O(n)

SPACE COMPLEXITY:
O(n)
