PROGRAM: Merge Dictionaries

PROBLEM:
Merge two dictionaries into a single dictionary.

INPUT:
{'a':1,'b':2}
{'c':3,'d':4}

OUTPUT:
{'a':1,'b':2,'c':3,'d':4}

LOGIC:
1. Take both dictionaries.
2. Combine using unpacking operator.
3. Store result in a new dictionary.

TIME COMPLEXITY:
O(n+m)

SPACE COMPLEXITY:
O(n+m)
